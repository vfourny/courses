## Pourquoi un router ?

Dans une SPA, une seule page HTML est chargée. La navigation entre les "pages" est gérée côté client : Vue Router intercepte les changements d'URL et affiche le composant correspondant **sans rechargement**.

Sans Vue Router, la navigation entre vues s'effectuerait manuellement avec `v-if` — ingérable dès qu'on a plusieurs pages.

## Installation

```sh
npm install vue-router
```

## Configurer le router

```ts
// src/router.ts
import { createRouter, createWebHistory } from 'vue-router'
import HomePage from './pages/HomePage.vue'
import LoginPage from './pages/auth/LoginPage.vue'
import DeckDetailPage from './pages/decks/DeckDetailPage.vue'

export const ROUTES = {
  HOME: '/',
  AUTH: {
    LOGIN: '/auth/login',
    REGISTER: '/auth/register',
  },
  DECKS: {
    DETAIL: '/decks/:id',
    CREATE: '/decks/create',
  },
} as const

const routes = [
  { path: ROUTES.HOME, component: HomePage },
  { path: ROUTES.AUTH.LOGIN, component: LoginPage },
  { path: ROUTES.DECKS.DETAIL, component: DeckDetailPage },
  { path: ROUTES.DECKS.CREATE, component: DeckDetailPage },
]

const router = createRouter({
  history: createWebHistory(),
  routes,
})

export default router
```

```ts
// main.ts
import naive from 'naive-ui'
import { createPinia } from 'pinia'
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'

const app = createApp(App)
app.use(createPinia())
app.use(router)
app.use(naive)
app.mount('#app')
```

> **`createWebHistory()`** utilise l'API History du navigateur (URLs propres sans `#`). Le serveur doit être configuré pour renvoyer `index.html` pour toutes les routes.

## Afficher les pages avec RouterView

`<RouterView />` est le composant qui affiche la page correspondant à l'URL courante. Il se place dans `App.vue`.

```vue
<!-- App.vue -->
<template>
  <NavMenu />
  <main>
    <RouterView />
  </main>
</template>

<script setup lang="ts">
import NavMenu from '@/components/NavMenu.component.vue'
</script>
```

## RouterLink : navigation déclarative

`<RouterLink>` génère un `<a>` qui navigue sans recharger la page.

```vue
<template>
  <nav>
    <RouterLink to="/">Accueil</RouterLink>
    <RouterLink to="/auth/login">Connexion</RouterLink>
    <RouterLink :to="`/decks/${deckId}`">Voir le deck</RouterLink>
  </nav>
</template>
```

## Routes dynamiques avec paramètres

Une route comme `/decks/:id` accepte n'importe quel identifiant. Le paramètre est accessible via `useRoute()`.

```ts
// src/router.ts
{ path: '/decks/:id', component: DeckDetailPage }
```

```vue
<!-- pages/decks/DeckDetailPage.vue -->
<template>
  <div>
    <p v-if="isLoading">Chargement...</p>
    <NCard v-else :title="deck?.name">
      <p>{{ deck?.description }}</p>
    </NCard>
  </div>
</template>

<script setup lang="ts">
import { onMounted, ref } from 'vue'
import { useRoute } from 'vue-router'
import { useApi } from '@/composables/useApi'

const route = useRoute()
const api = useApi()
const deck = ref(null)
const isLoading = ref(true)

onMounted(async () => {
  const id = route.params.id as string
  deck.value = await api.getDeck(id)
  isLoading.value = false
})
</script>
```

## Navigation programmatique

`useRouter()` permet de naviguer par code (après une action, une connexion, etc.).

```ts
import { useRouter } from 'vue-router'

const router = useRouter()

// Naviguer vers une route
router.push('/auth/login')
router.push({ path: `/decks/${id}` })

// Revenir en arrière
router.back()

// Remplacer l'historique (pas de retour possible)
router.replace('/home')
```

## Navigation Guards

Les **navigation guards** permettent de contrôler l'accès aux routes : rediriger l'utilisateur non connecté vers la page de connexion, empêcher un utilisateur connecté d'accéder à la page de login, etc.

### Définir des métadonnées sur les routes

```ts
// src/router.ts
const routes = [
  {
    path: '/',
    component: HomePage,
    meta: { requiresAuth: true }, // Nécessite d'être connecté
  },
  {
    path: '/auth/login',
    component: LoginPage,
    meta: { guestOnly: true }, // Accessible uniquement aux non-connectés
  },
  {
    path: '/decks/create',
    component: DeckFormPage,
    meta: { requiresAuth: true },
  },
]
```

### Implémenter le guard global

```ts
// src/router.ts
import { useAuthStore } from './store/auth'

router.beforeEach((to) => {
  const auth = useAuthStore()

  // Route protégée mais utilisateur non connecté
  if (to.meta.requiresAuth && !auth.isAuthenticated) {
    return '/auth/login'
  }

  // Route invité mais utilisateur déjà connecté
  if (to.meta.guestOnly && auth.isAuthenticated) {
    return '/'
  }

  return true // Autoriser la navigation
})
```

> **Remarque :** `router.beforeEach` est appelé avant chaque changement de route. Retourner une chaîne redirige vers cette URL. Retourner `true` (ou rien) autorise la navigation.

### Typer les métadonnées (TypeScript)

Pour que TypeScript reconnaisse `meta.requiresAuth`, déclarez les types dans un fichier dédié :

```ts
// src/router.ts (en haut du fichier)
declare module 'vue-router' {
  interface RouteMeta {
    requiresAuth?: boolean
    guestOnly?: boolean
  }
}
```

## Composant de navigation

```vue
<!-- src/components/NavMenu.component.vue -->
<template>
  <NLayoutHeader bordered style="padding: 0 16px">
    <NSpace align="center" justify="space-between" style="height: 100%">
      <NSpace>
        <NButton
          v-for="item in menuItems"
          :key="item.path"
          quaternary
          :type="isActive(item.path) ? 'primary' : 'default'"
          @click="router.push(item.path)"
        >
          {{ item.label }}
        </NButton>
      </NSpace>

      <NButton v-if="isAuthenticated" @click="handleLogout">
        Déconnexion
      </NButton>
    </NSpace>
  </NLayoutHeader>
</template>

<script setup lang="ts">
import { useRoute, useRouter } from 'vue-router'
import { storeToRefs } from 'pinia'
import { useAuthStore } from '@/store/auth'

const router = useRouter()
const route = useRoute()
const authStore = useAuthStore()
const { isAuthenticated } = storeToRefs(authStore)

const menuItems = [
  { label: 'Accueil', path: '/' },
  { label: 'Mes Decks', path: '/decks' },
  { label: 'Jouer', path: '/game' },
]

const isActive = (path: string) => route.path === path

const handleLogout = () => {
  authStore.logout()
  router.push('/auth/login')
}
</script>
```

## Résumé

| Élément | Rôle |
| --- | --- |
| `createRouter()` | Crée l'instance du router |
| `<RouterView />` | Affiche la page courante |
| `<RouterLink>` | Navigation déclarative (lien) |
| `useRouter()` | Navigation programmatique |
| `useRoute()` | Accès aux params, query, meta |
| `router.beforeEach()` | Guard global (auth, redirections) |
| `meta.requiresAuth` | Marquer une route comme protégée |
