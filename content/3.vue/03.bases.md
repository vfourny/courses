Dans ce chapitre, on commence à construire notre **Movie Watchlist** — une application de gestion de films à voir et déjà vus. On pose les bases : données réactives, valeurs calculées, surveillance des changements et directives pour afficher la liste de films.

## Réactivité

La réactivité est au cœur de Vue 3 : quand vos données changent, l'interface se met à jour automatiquement. Vue propose plusieurs primitives réactives selon la nature des données.

### ref()

`ref()` crée une valeur réactive. Elle s'utilise pour les types simples (nombre, chaîne, booléen) mais aussi pour les objets.

```vue
<template>
  <div>
    <p>Films dans la watchlist : {{ movies.length }}</p>
    <p>Premier film : {{ movies[0].title }}</p>
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'

interface Movie {
  id: number
  title: string
  genre: string
  year: number
  seen: boolean
}

const movies = ref<Movie[]>([
  { id: 1, title: 'Inception', genre: 'Sci-Fi', year: 2010, seen: true },
  { id: 2, title: 'The Dark Knight', genre: 'Action', year: 2008, seen: false },
  { id: 3, title: 'Interstellar', genre: 'Sci-Fi', year: 2014, seen: false },
])
</script>
```

> **Remarque :** Dans le `<template>`, Vue déroule automatiquement le `.value`. Dans le `<script>`, il faut toujours passer par `movies.value` pour lire ou modifier le tableau.

### reactive()

`reactive()` crée un objet entièrement réactif. Il est particulièrement adapté pour les formulaires ou tout état structuré.

```vue
<template>
  <div>
    <p>{{ newMovie.title }} ({{ newMovie.year }})</p>
    <input v-model="newMovie.title" placeholder="Titre du film" />
    <input v-model.number="newMovie.year" type="number" placeholder="Année" />
  </div>
</template>

<script setup lang="ts">
import { reactive } from 'vue'

const newMovie = reactive({
  title: '',
  year: 2024,
  seen: false,
})
</script>
```

> **Remarque :** Avec `reactive()`, pas besoin de `.value` — les propriétés sont directement accessibles. Attention, `reactive()` ne fonctionne qu'avec des objets, pas avec les types primitifs.

### computed()

`computed()` crée une valeur dérivée, recalculée automatiquement uniquement quand ses dépendances changent.

```vue
<template>
  <div>
    <input v-model="search" placeholder="Rechercher un film..." />
    <p>Films trouvés : {{ filteredMovies.length }}</p>
    <ul>
      <li v-for="movie in filteredMovies" :key="movie.id">
        {{ movie.title }} ({{ movie.year }})
      </li>
    </ul>
  </div>
</template>

<script setup lang="ts">
import { computed, ref } from 'vue'

interface Movie { id: number; title: string; year: number; seen: boolean }

const search = ref<string>('')
const movies = ref<Movie[]>([
  { id: 1, title: 'Inception', year: 2010, seen: true },
  { id: 2, title: 'The Dark Knight', year: 2008, seen: false },
])

const filteredMovies = computed(() =>
  movies.value.filter((m) =>
    m.title.toLowerCase().includes(search.value.toLowerCase())
  )
)
</script>
```

### Différence entre `computed` et une fonction

| Aspect | `computed` | Fonction classique |
| --- | --- | --- |
| **Mémorisation** | Oui, résultat mis en cache | Non, recalculé à chaque appel |
| **Utilisation** | Valeur dérivée de l'état | Action ou modification d'état |
| **Réactivité** | Recalcul automatique si dépendances changent | Appel manuel requis |

### watch()

`watch()` permet d'exécuter du code en réaction au changement d'une valeur réactive. Utile pour déclencher des effets secondaires (appel API, log, etc.).

```vue
<script setup lang="ts">
import { ref, watch } from 'vue'

const search = ref<string>('')

watch(search, (newValue, oldValue) => {
  console.log(`Recherche passée de "${oldValue}" à "${newValue}"`)
})
</script>
```

Pour surveiller un objet `reactive` ou plusieurs sources :

```ts
// Surveiller une propriété précise d'un reactive
watch(() => newMovie.title, (newTitle) => {
  console.log('Nouveau titre :', newTitle)
})

// Surveiller plusieurs sources
watch([search, () => newMovie.title], ([newSearch, newTitle]) => {
  console.log(newSearch, newTitle)
})
```

## Cycle de vie des composants

Vue appelle des **hooks** à des moments précis de la vie d'un composant. Le plus utilisé est `onMounted`, appelé une fois que le composant est inséré dans le DOM — idéal pour déclencher un appel API initial.

```vue
<script setup lang="ts">
import { onMounted, ref } from 'vue'

const movies = ref([])

onMounted(() => {
  console.log('Application prête')
  // Ici on pourrait charger les films depuis une API
})
</script>
```

Les principaux hooks :

| Hook | Moment d'appel |
| --- | --- |
| `onMounted` | Après l'insertion du composant dans le DOM |
| `onUpdated` | Après une mise à jour du DOM |
| `onUnmounted` | Avant la destruction du composant |
| `onBeforeMount` | Juste avant le montage |

> **Documentation :** La liste complète des hooks est disponible sur [fr.vuejs.org/guide/essentials/lifecycle](https://fr.vuejs.org/guide/essentials/lifecycle).

## Directives Vue

Vue fournit des **directives** pour manipuler le DOM de manière déclarative directement dans le template.

### v-if / v-else / v-else-if

Affiche ou masque un élément selon une condition. L'élément est **créé ou détruit** dans le DOM.

```vue
<template>
  <p v-if="isLoggedIn">Bienvenue !</p>
  <p v-else>Veuillez vous connecter.</p>
</template>
```

### v-show

Affiche ou masque un élément via CSS (`display: none`). L'élément reste toujours dans le DOM.

```vue
<template>
  <p v-show="isLoggedIn">Bienvenue !</p>
</template>
```

### Différence v-if vs v-show

| | `v-if` | `v-show` |
| --- | --- | --- |
| **DOM** | Élément créé / détruit | Toujours présent |
| **Performance** | Coût au changement d'état | Coût initial plus élevé |
| **Usage** | Condition rarement changeante | Basculement fréquent |

### v-for

Génère une liste d'éléments dynamiquement. Toujours utiliser `:key` avec un identifiant unique.

```vue
<template>
  <ul>
    <li v-for="movie in movies" :key="movie.id">
      {{ movie.title }} — {{ movie.year }} — {{ movie.genre }}
    </li>
  </ul>
</template>

<script setup lang="ts">
import { ref } from 'vue'

interface Movie {
  id: number
  title: string
  genre: string
  year: number
  seen: boolean
}

const movies = ref<Movie[]>([
  { id: 1, title: 'Inception', genre: 'Sci-Fi', year: 2010, seen: true },
  { id: 2, title: 'The Dark Knight', genre: 'Action', year: 2008, seen: false },
])
</script>
```

### v-bind

Lie dynamiquement une valeur à un attribut HTML. Le raccourci est `:`.

```vue
<template>
  <!-- Forme longue -->
  <button v-bind:disabled="movie.seen">Déjà vu</button>

  <!-- Raccourci : -->
  <button :disabled="movie.seen">Déjà vu</button>
  <img :src="movie.posterUrl" :alt="movie.title" />
</template>
```

### v-model

Crée une liaison **bidirectionnelle** entre un champ de formulaire et une donnée réactive.

```vue
<template>
  <input v-model="search" placeholder="Rechercher..." />
  <p>Vous cherchez : {{ search }}</p>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const search = ref<string>('')
</script>
```

### v-on

Écoute des événements DOM. Le raccourci est `@`.

```vue
<template>
  <!-- Forme longue -->
  <button v-on:click="toggleSeen(movie)">Marquer comme vu</button>

  <!-- Raccourci @ -->
  <button @click="toggleSeen(movie)">Marquer comme vu</button>
  <input @keyup.enter="search = ''" v-model="search" />
</template>
```

### Différence v-bind vs v-model

- `v-bind` : liaison **unidirectionnelle** (données → DOM). Utiliser pour les attributs comme `src`, `href`, `disabled`.
- `v-model` : liaison **bidirectionnelle** (données ↔ DOM). Utiliser pour les inputs, selects, textareas.

## Exemple complet

Voici le composant Movie Watchlist qui combine réactivité, computed, watch, cycle de vie et directives :

```vue
<template>
  <div>
    <input v-model="search" placeholder="Rechercher un film..." />
    <p v-if="filteredMovies.length === 0">Aucun film trouvé.</p>
    <ul>
      <li v-for="movie in filteredMovies" :key="movie.id">
        {{ movie.title }} ({{ movie.year }}) — {{ movie.genre }}
        <span v-if="movie.seen">✓ Vu</span>
        <span v-else>À voir</span>
        <button @click="movie.seen = !movie.seen">Basculer</button>
      </li>
    </ul>
    <p>{{ filteredMovies.length }} film(s) trouvé(s)</p>
  </div>
</template>

<script setup lang="ts">
import { computed, onMounted, ref, watch } from 'vue'

interface Movie {
  id: number
  title: string
  genre: string
  year: number
  seen: boolean
}

const search = ref<string>('')

const movies = ref<Movie[]>([
  { id: 1, title: 'Inception', genre: 'Sci-Fi', year: 2010, seen: true },
  { id: 2, title: 'The Dark Knight', genre: 'Action', year: 2008, seen: false },
  { id: 3, title: 'Interstellar', genre: 'Sci-Fi', year: 2014, seen: false },
  { id: 4, title: 'Parasite', genre: 'Thriller', year: 2019, seen: true },
  { id: 5, title: 'Dune', genre: 'Sci-Fi', year: 2021, seen: false },
  { id: 6, title: 'Everything Everywhere All at Once', genre: 'Action', year: 2022, seen: true },
])

const filteredMovies = computed(() =>
  movies.value.filter((m) =>
    m.title.toLowerCase().includes(search.value.toLowerCase())
  )
)

watch(search, (newVal) => {
  console.log('Recherche :', newVal)
})

onMounted(() => {
  console.log('Application prête')
})
</script>
```
