## Création et utilisation d'un composant

Les **composants** sont des éléments réutilisables qui permettent de structurer une application Vue en morceaux indépendants. Chaque composant est un fichier `.vue` qui encapsule son template, sa logique et ses styles.

Reprenons le compteur de l'exemple précédent et extrayons-le dans un composant dédié.

```vue
<!-- src/components/Counter.component.vue -->
<template>
  <div>
    <p>Compteur : {{ counter }}</p>
    <p>Double : {{ doubleCounter }}</p>
    <button @click="counter++">Incrémenter</button>
    <button :disabled="counter === 0" @click="reset">Réinitialiser</button>
  </div>
</template>

<script setup lang="ts">
import { computed, ref } from 'vue'

const counter = ref<number>(0)
const doubleCounter = computed(() => counter.value * 2)

const reset = () => {
  counter.value = 0
}
</script>
```

```vue
<!-- src/App.vue -->
<template>
  <div>
    <CounterComponent />
  </div>
</template>

<script setup lang="ts">
import CounterComponent from './components/Counter.component.vue'
</script>
```

> **Remarque :** Vue 3 avec `<script setup>` importe automatiquement les composants dans le template dès qu'ils sont importés dans le script. Pas besoin de les déclarer dans `components: {}`.

## Props : passer des données au composant enfant

Les **props** permettent à un composant parent de transmettre des données à un composant enfant. En Vue 3, on les définit avec la macro `defineProps<{}>()` (pas d'import nécessaire).

#### Composant enfant (`UserList.component.vue`)

```vue
<template>
  <div>
    <h2>Liste des utilisateurs</h2>
    <ul>
      <li v-for="user in users" :key="user.id">
        {{ user.name }} — {{ user.age }} ans
      </li>
    </ul>
  </div>
</template>

<script setup lang="ts">
interface User {
  id: number
  name: string
  age: number
}

const props = defineProps<{
  users: User[]
}>()
</script>
```

#### Composant parent (`App.vue`)

```vue
<template>
  <div>
    <CounterComponent />
    <UserList :users="users" />
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import CounterComponent from './components/Counter.component.vue'
import UserList from './components/UserList.component.vue'

interface User {
  id: number
  name: string
  age: number
}

const users = ref<User[]>([
  { id: 1, name: 'Alice', age: 25 },
  { id: 2, name: 'Bob', age: 30 },
  { id: 3, name: 'Charlie', age: 22 },
])
</script>
```

> **TypeScript :** Définir les props avec `defineProps<{}>()` permet à TypeScript de valider les types à la compilation. Si vous devez donner des valeurs par défaut, utilisez `withDefaults(defineProps<{}>(), { ... })`.

## Émission d'événements : du composant enfant vers le parent

Lorsqu'un composant enfant doit communiquer avec son parent, on utilise `defineEmits<{}>()` pour déclarer les événements émis.

Supposons que je veuille afficher un utilisateur dans le parent lorsque l'on clique dessus dans la liste.

#### Composant enfant (`UserList.component.vue`)

```vue
<template>
  <div>
    <h2>Liste des utilisateurs</h2>
    <ul>
      <li
        v-for="user in users"
        :key="user.id"
        style="cursor: pointer"
        @click="emit('selectUser', user)"
      >
        {{ user.name }} — {{ user.age }} ans
      </li>
    </ul>
  </div>
</template>

<script setup lang="ts">
interface User {
  id: number
  name: string
  age: number
}

defineProps<{
  users: User[]
}>()

const emit = defineEmits<{
  selectUser: [user: User]
}>()
</script>
```

#### Composant parent (`App.vue`)

```vue
<template>
  <div>
    <p v-if="selectedUser">Sélectionné : {{ selectedUser.name }}</p>
    <UserList :users="users" @select-user="onSelectUser" />
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import UserList from './components/UserList.component.vue'

interface User {
  id: number
  name: string
  age: number
}

const users = ref<User[]>([
  { id: 1, name: 'Alice', age: 25 },
  { id: 2, name: 'Bob', age: 30 },
])

const selectedUser = ref<User | null>(null)

const onSelectUser = (user: User) => {
  selectedUser.value = user
}
</script>
```

> **Convention de nommage :** Les événements sont déclarés en `camelCase` dans `defineEmits` (`selectUser`) et écoutés en `kebab-case` dans le template parent (`@select-user`). Vue effectue la conversion automatiquement.

## Slots : injecter du contenu dans un composant

Les **slots** permettent au composant parent d'injecter du contenu HTML dans un emplacement défini par l'enfant. C'est le mécanisme d'extension et de composition des composants.

#### Composant enfant avec slot (`UserList.component.vue`)

```vue
<template>
  <div>
    <h2>Liste des utilisateurs</h2>
    <ul>
      <li
        v-for="user in users"
        :key="user.id"
        @click="emit('selectUser', user)"
      >
        {{ user.name }} — {{ user.age }} ans
      </li>
    </ul>

    <!-- Emplacement pour contenu injecté par le parent -->
    <slot></slot>
  </div>
</template>

<script setup lang="ts">
interface User {
  id: number
  name: string
  age: number
}

defineProps<{
  users: User[]
}>()

const emit = defineEmits<{
  selectUser: [user: User]
}>()
</script>
```

#### Composant parent utilisant le slot

```vue
<template>
  <div>
    <p v-if="selectedUser">Sélectionné : {{ selectedUser.name }}</p>

    <UserList :users="users" @select-user="onSelectUser">
      <!-- Ce contenu est injecté dans le <slot> de l'enfant -->
      <div>
        <input v-model="newUser.name" placeholder="Nom" />
        <input v-model.number="newUser.age" type="number" placeholder="Âge" />
        <button @click="addUser">Ajouter</button>
      </div>
    </UserList>
  </div>
</template>

<script setup lang="ts">
import { reactive, ref } from 'vue'
import UserList from './components/UserList.component.vue'

interface User {
  id: number
  name: string
  age: number
}

const users = ref<User[]>([
  { id: 1, name: 'Alice', age: 25 },
  { id: 2, name: 'Bob', age: 30 },
])

const selectedUser = ref<User | null>(null)
const newUser = reactive({ name: '', age: 0 })

const onSelectUser = (user: User) => {
  selectedUser.value = user
}

const addUser = () => {
  if (newUser.name && newUser.age) {
    users.value.push({ id: Date.now(), ...newUser })
    newUser.name = ''
    newUser.age = 0
  }
}
</script>
```

## Organisation des fichiers

Une structure courante pour les composants Vue :

```
src/
├── components/           # Composants réutilisables
│   ├── Counter.component.vue
│   └── UserList.component.vue
├── pages/                # Composants-pages (liés au router)
│   ├── HomePage.vue
│   └── ProfilePage.vue
├── types/                # Interfaces TypeScript partagées
│   └── index.ts
├── App.vue
└── main.ts
```

> **Convention :** Nommer les composants réutilisables avec le suffixe `.component.vue` et les pages avec `.vue` (ou `.page.vue`). Les interfaces partagées entre plusieurs composants vont dans `src/types/`.
