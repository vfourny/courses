## HTTP vs WebSocket

Les appels API classiques suivent un modèle **requête/réponse** : le client demande, le serveur répond, la connexion se ferme. Ce modèle ne convient pas aux fonctionnalités en temps réel (jeu en ligne, chat, notifications...) car le serveur ne peut pas **pousser** de données sans que le client ne les demande.

**WebSocket** maintient une connexion bidirectionnelle persistante entre le client et le serveur. Les deux parties peuvent envoyer des messages à tout moment.

**Socket.io** est une librairie qui simplifie l'utilisation des WebSockets en ajoutant :
- Reconnexion automatique
- Gestion des événements nommés
- Compatibilité navigateurs
- Authentification via token

```
HTTP (REST)                    WebSocket / Socket.io
──────────────────             ──────────────────────────────
Client → Serveur (requête)     Client ←→ Serveur (connexion persistante)
Serveur → Client (réponse)     Événements dans les deux sens
Connexion fermée               Connexion maintenue ouverte
```

## Installation

```sh
npm install socket.io-client
```

## Connexion au serveur

```ts
import { io } from 'socket.io-client'

const socket = io('http://localhost:3001', {
  auth: { token: 'eyJ...' }, // Token JWT pour l'authentification
})

socket.on('connect', () => {
  console.log('Connecté :', socket.id)
})

socket.on('disconnect', () => {
  console.log('Déconnecté')
})
```

## Émettre et écouter des événements

```ts
// Émettre un événement vers le serveur
socket.emit('createRoom', { deckId: 42 })

// Écouter un événement du serveur
socket.on('roomCreated', (data) => {
  console.log('Salon créé :', data.roomId)
})

// Supprimer un listener
socket.off('roomCreated')
```

## Intégration dans un store Pinia

La bonne pratique est d'encapsuler la logique Socket.io dans un **store Pinia**. Le store gère la connexion, les événements et l'état du jeu. Les composants n'interagissent qu'avec le store.

```ts
// src/store/game.ts
import { defineStore } from 'pinia'
import { io, type Socket } from 'socket.io-client'
import { computed, ref } from 'vue'
import { useRouter } from 'vue-router'

interface Room {
  id: number
  name: string
  playerCount: number
}

interface GameState {
  roomId: number
  currentPlayerSocketId: string
  // ...autres propriétés de l'état du jeu
}

export const useGameStore = defineStore('game', () => {
  const router = useRouter()

  const socket = ref<Socket | null>(null)
  const socketId = ref<string | null>(null)
  const rooms = ref<Room[]>([])
  const gameState = ref<GameState | null>(null)
  const error = ref<string | null>(null)

  const isConnected = computed(() => !!socketId.value)
  const isMyTurn = computed(() => {
    if (!socketId.value || !gameState.value) return false
    return gameState.value.currentPlayerSocketId === socketId.value
  })

  // ─── Connexion ───────────────────────────────────────────────

  const connect = (token: string): void => {
    if (socket.value?.connected) return

    const s = io(import.meta.env.VITE_SOCKET_URL, {
      auth: { token },
    })
    socket.value = s

    // Événements système
    s.on('connect', () => {
      socketId.value = s.id ?? null
      error.value = null
    })

    s.on('disconnect', () => {
      socketId.value = null
    })

    s.on('connect_error', (err: Error) => {
      error.value = err.message
    })

    // Événements métier
    s.on('roomsList', (data: Room[]) => {
      rooms.value = data
    })

    s.on('gameStarted', (data: { gameState: GameState }) => {
      gameState.value = data.gameState
      router.push('/game') // Redirection automatique
    })

    s.on('gameStateUpdated', (data: { gameState: GameState }) => {
      gameState.value = data.gameState
    })

    s.on('error', (data: { message: string }) => {
      error.value = data.message
    })
  }

  const disconnect = (): void => {
    socket.value?.disconnect()
    socket.value = null
    socketId.value = null
    rooms.value = []
    gameState.value = null
    error.value = null
  }

  // ─── Actions de jeu ──────────────────────────────────────────

  const getRooms = (): void => {
    socket.value?.emit('getRooms')
  }

  const createRoom = (deckId: number): void => {
    error.value = null
    socket.value?.emit('createRoom', { deckId })
  }

  const joinRoom = (roomId: number, deckId: number): void => {
    error.value = null
    socket.value?.emit('joinRoom', { roomId, deckId })
  }

  const playCard = (cardIndex: number): void => {
    socket.value?.emit('playCard', { roomId: gameState.value?.roomId, cardIndex })
  }

  const endTurn = (): void => {
    socket.value?.emit('endTurn', { roomId: gameState.value?.roomId })
  }

  return {
    socketId,
    rooms,
    gameState,
    error,
    isConnected,
    isMyTurn,
    connect,
    disconnect,
    getRooms,
    createRoom,
    joinRoom,
    playCard,
    endTurn,
  }
})
```

## Utiliser le store dans un composant

```vue
<!-- pages/game/LobbyPage.vue -->
<template>
  <div>
    <NAlert v-if="error" type="error">{{ error }}</NAlert>

    <NCard title="Salons disponibles">
      <NSpace vertical>
        <NCard
          v-for="room in rooms"
          :key="room.id"
          :title="`Salon #${room.id}`"
          size="small"
        >
          <template #footer>
            <NButton type="primary" @click="joinRoom(room.id, selectedDeckId)">
              Rejoindre
            </NButton>
          </template>
        </NCard>
      </NSpace>
    </NCard>

    <NButton type="success" @click="createRoom(selectedDeckId)">
      Créer un salon
    </NButton>
  </div>
</template>

<script setup lang="ts">
import { onMounted, onUnmounted } from 'vue'
import { storeToRefs } from 'pinia'
import { useGameStore } from '@/store/game'
import { useAuthStore } from '@/store/auth'

const gameStore = useGameStore()
const authStore = useAuthStore()
const { rooms, error } = storeToRefs(gameStore)

const selectedDeckId = 1 // À remplacer par la sélection réelle

onMounted(() => {
  // Connexion au serveur Socket.io avec le token JWT
  if (authStore.token) {
    gameStore.connect(authStore.token)
    gameStore.getRooms()
  }
})

onUnmounted(() => {
  // Se déconnecter proprement en quittant la page
  gameStore.disconnect()
})

const { createRoom, joinRoom } = gameStore
</script>
```

## Nettoyer les connexions

Toujours se déconnecter dans `onUnmounted` pour éviter les fuites mémoire et les listeners orphelins :

```ts
onUnmounted(() => {
  gameStore.disconnect()
  // ou directement : socket.off('roomsList')
})
```


## Résumé

| Élément | Rôle |
| --- | --- |
| `io(url, options)` | Se connecter au serveur Socket.io |
| `socket.emit(event, data)` | Envoyer un événement au serveur |
| `socket.on(event, callback)` | Écouter un événement du serveur |
| `socket.off(event)` | Supprimer un listener |
| `socket.disconnect()` | Se déconnecter proprement |
| Store Pinia | Centralise connexion, état et actions |

> **Pour aller plus loin :** La documentation complète de Socket.io est disponible sur [socket.io/docs/v4](https://socket.io/docs/v4/).
