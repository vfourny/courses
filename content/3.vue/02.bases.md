## Réactivité

La réactivité est au cœur de Vue 3 : quand vos données changent, l'interface se met à jour automatiquement. Vue propose plusieurs primitives réactives selon la nature des données.

### ref()

`ref()` crée une valeur réactive. Elle s'utilise pour les types simples (nombre, chaîne, booléen) mais aussi pour les objets.

```vue
<template>
  <div>
    <p>Compteur : {{ counter }}</p>
    <button @click="counter++">Incrémenter</button>
    <button @click="reset">Réinitialiser</button>
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const counter = ref<number>(0)

const reset = () => {
  counter.value = 0
}
</script>
```

> **Remarque :** Dans le `<template>`, Vue déroule automatiquement le `.value`. Dans le `<script>`, il faut toujours passer par `counter.value` pour lire ou modifier la valeur.

### reactive()

`reactive()` crée un objet entièrement réactif. Il est particulièrement adapté pour les formulaires ou tout état structuré.

```vue
<template>
  <div>
    <p>{{ user.name }} ({{ user.age }} ans)</p>
    <input v-model="user.name" placeholder="Nom" />
    <input v-model.number="user.age" type="number" placeholder="Âge" />
  </div>
</template>

<script setup lang="ts">
import { reactive } from 'vue'

const user = reactive({
  name: '',
  age: 0,
})
</script>
```

> **Remarque :** Avec `reactive()`, pas besoin de `.value` — les propriétés sont directement accessibles. Attention, `reactive()` ne fonctionne qu'avec des objets, pas avec les types primitifs.

### computed()

`computed()` crée une valeur dérivée, recalculée automatiquement uniquement quand ses dépendances changent.

```vue
<template>
  <div>
    <p>Compteur : {{ counter }}</p>
    <p>Double : {{ doubleCounter }}</p>
    <button @click="counter++">Incrémenter</button>
  </div>
</template>

<script setup lang="ts">
import { computed, ref } from 'vue'

const counter = ref<number>(0)
const doubleCounter = computed(() => counter.value * 2)
</script>
```

### Différence entre `computed` et une fonction

| Aspect | `computed` | Fonction classique |
| --- | --- | --- |
| **Mémorisation** | Oui, résultat mis en cache | Non, recalculé à chaque appel |
| **Utilisation** | Valeur dérivée de l'état | Action ou modification d'état |
| **Réactivité** | Recalcul automatique si dépendances changent | Appel manuel requis |

### watch()

`watch()` permet d'exécuter du code en réaction au changement d'une valeur réactive. Utile pour déclencher des effets secondaires (appel API, log, etc.).

```vue
<script setup lang="ts">
import { ref, watch } from 'vue'

const counter = ref<number>(0)

watch(counter, (newValue, oldValue) => {
  console.log(`Compteur passé de ${oldValue} à ${newValue}`)
})
</script>
```

Pour surveiller un objet `reactive` ou plusieurs sources :

```ts
// Surveiller une propriété précise
watch(() => user.name, (newName) => {
  console.log('Nouveau nom :', newName)
})

// Surveiller plusieurs sources
watch([counter, () => user.name], ([newCount, newName]) => {
  console.log(newCount, newName)
})
```

## Cycle de vie des composants

Vue appelle des **hooks** à des moments précis de la vie d'un composant. Le plus utilisé est `onMounted`, appelé une fois que le composant est inséré dans le DOM — idéal pour déclencher un appel API initial.

```vue
<script setup lang="ts">
import { onMounted, ref } from 'vue'

const message = ref<string>('Chargement...')

onMounted(() => {
  message.value = 'Composant prêt !'
})
</script>
```

Les principaux hooks :

| Hook | Moment d'appel |
| --- | --- |
| `onMounted` | Après l'insertion du composant dans le DOM |
| `onUpdated` | Après une mise à jour du DOM |
| `onUnmounted` | Avant la destruction du composant |
| `onBeforeMount` | Juste avant le montage |

> **Documentation :** La liste complète des hooks est disponible sur [fr.vuejs.org/guide/essentials/lifecycle](https://fr.vuejs.org/guide/essentials/lifecycle).

## Directives Vue

Vue fournit des **directives** pour manipuler le DOM de manière déclarative directement dans le template.

### v-if / v-else / v-else-if

Affiche ou masque un élément selon une condition. L'élément est **créé ou détruit** dans le DOM.

```vue
<template>
  <p v-if="isLoggedIn">Bienvenue !</p>
  <p v-else>Veuillez vous connecter.</p>
</template>
```

### v-show

Affiche ou masque un élément via CSS (`display: none`). L'élément reste toujours dans le DOM.

```vue
<template>
  <p v-show="isLoggedIn">Bienvenue !</p>
</template>
```

### Différence v-if vs v-show

| | `v-if` | `v-show` |
| --- | --- | --- |
| **DOM** | Élément créé / détruit | Toujours présent |
| **Performance** | Coût au changement d'état | Coût initial plus élevé |
| **Usage** | Condition rarement changeante | Basculement fréquent |

### v-for

Génère une liste d'éléments dynamiquement. Toujours utiliser `:key` avec un identifiant unique.

```vue
<template>
  <ul>
    <li v-for="user in users" :key="user.id">
      {{ user.name }} — {{ user.age }} ans
    </li>
  </ul>
</template>

<script setup lang="ts">
import { ref } from 'vue'

interface User {
  id: number
  name: string
  age: number
}

const users = ref<User[]>([
  { id: 1, name: 'Alice', age: 25 },
  { id: 2, name: 'Bob', age: 30 },
])
</script>
```

### v-bind

Lie dynamiquement une valeur à un attribut HTML. Le raccourci est `:`.

```vue
<template>
  <!-- Forme longue -->
  <button v-bind:disabled="counter === 0">Réinitialiser</button>

  <!-- Raccourci : -->
  <button :disabled="counter === 0">Réinitialiser</button>
  <img :src="imageUrl" :alt="imageAlt" />
</template>
```

### v-model

Crée une liaison **bidirectionnelle** entre un champ de formulaire et une donnée réactive.

```vue
<template>
  <input v-model="search" placeholder="Rechercher..." />
  <p>Vous cherchez : {{ search }}</p>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const search = ref<string>('')
</script>
```

### v-on

Écoute des événements DOM. Le raccourci est `@`.

```vue
<template>
  <!-- Forme longue -->
  <button v-on:click="reset">Réinitialiser</button>

  <!-- Raccourci @ -->
  <button @click="reset">Réinitialiser</button>
  <input @keyup.enter="submit" v-model="value" />
</template>
```

### Différence v-bind vs v-model

- `v-bind` : liaison **unidirectionnelle** (données → DOM). Utiliser pour les attributs comme `src`, `href`, `disabled`.
- `v-model` : liaison **bidirectionnelle** (données ↔ DOM). Utiliser pour les inputs, selects, textareas.

## Exemple complet

Voici un composant qui combine réactivité, computed, watch et directives :

```vue
<template>
  <div>
    <input v-model="search" placeholder="Filtrer les utilisateurs..." />
    <p v-if="filteredUsers.length === 0">Aucun résultat.</p>
    <ul>
      <li v-for="user in filteredUsers" :key="user.id">
        {{ user.name }} — {{ user.age }} ans
      </li>
    </ul>
    <p>Total : {{ filteredUsers.length }} utilisateur(s)</p>
  </div>
</template>

<script setup lang="ts">
import { computed, ref, watch } from 'vue'

interface User {
  id: number
  name: string
  age: number
}

const search = ref<string>('')

const users = ref<User[]>([
  { id: 1, name: 'Alice', age: 25 },
  { id: 2, name: 'Bob', age: 30 },
  { id: 3, name: 'Charlie', age: 22 },
])

const filteredUsers = computed(() =>
  users.value.filter((u) =>
    u.name.toLowerCase().includes(search.value.toLowerCase())
  )
)

watch(search, (newVal) => {
  console.log('Recherche :', newVal)
})
</script>
```
