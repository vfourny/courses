Dans ce chapitre, on reprend le Movie Watchlist du chapitre précédent et on remplace chaque élément HTML brut par son équivalent **Naive UI**.

## Pourquoi utiliser une librairie UI ?

Sans librairie UI, chaque bouton, formulaire ou mise en page doit être conçu et stylisé manuellement. Une librairie comme **Naive UI** offre :

- Des **composants préconçus** (boutons, inputs, cartes, grilles…)
- Un **design cohérent** appliqué uniformément
- Des composants **accessibles** et **testés**
- Un **gain de temps** pour se concentrer sur la logique métier

## Installation et configuration

```sh
npm install naive-ui
```

Enregistrement global dans `main.ts` — tous les composants sont disponibles partout sans import supplémentaire :

```ts
// main.ts
import naive from 'naive-ui'
import { createApp } from 'vue'
import App from './App.vue'

const app = createApp(App)
app.use(naive)
app.mount('#app')
```

> **Remarque :** Dans Naive UI, le `v-model` des inputs s'écrit `v-model:value` au lieu de `v-model`. C'est une particularité de la librairie.

## Composants essentiels

### NButton

Remplace les `<button>` HTML. Plusieurs types visuels disponibles.

```vue
<template>
  <NButton type="primary" @click="emit('toggle-seen', movie)">Basculer</NButton>
</template>
```

Types disponibles : `default`, `primary`, `info`, `success`, `warning`, `error`.

### NInput

Remplace les `<input>` HTML. Utilise `v-model:value` au lieu de `v-model`.

```vue
<template>
  <NInput v-model:value="search" placeholder="Rechercher un film..."/>
</template>
```

### NTag

Remplace les `<span>` de statut. Idéal pour afficher l'état vu/à voir d'un film.

```vue
<template>
  <NTag :type="movie.seen ? 'success' : 'default'">
    {{ movie.seen ? '✓ Vu' : 'À voir' }}
  </NTag>
</template>
```

### NCard

Remplace les `<li>` ou `<div>` de carte. Propose des slots `#header-extra` et `#footer`.

```vue
<template>
  <NCard :title="movie.title">
    <template #header-extra>
      <NTag :type="movie.seen ? 'success' : 'default'">
        {{ movie.seen ? '✓ Vu' : 'À voir' }}
      </NTag>
    </template>
    <p>{{ movie.genre }} — {{ movie.year }}</p>
    <template #footer>
      <NButton type="primary" @click="emit('toggle-seen', movie)">Basculer</NButton>
    </template>
  </NCard>
</template>
```

### NGrid et NGi

Remplace la `<ul>` / `<li>` pour une mise en page en grille responsive.

```vue
<template>
  <NGrid :cols="3" :x-gap="16" :y-gap="16">
    <NGi v-for="movie in movies" :key="movie.id">
      <MovieCard :movie="movie" @toggle-seen="emit('toggle-seen', $event)"/>
    </NGi>
  </NGrid>
</template>
```

### NSpace

Gère l'espacement et l'alignement entre éléments, en remplacement des `<div>` de layout.

```vue
<template>
  <NSpace justify="space-between" align="center">
    <NInput v-model:value="search" placeholder="Rechercher un film..."/>
    <NTag type="success">{{ seenMovies.length }} vu(s) sur {{ movies.length }}</NTag>
  </NSpace>
</template>
```

## Exemple complet

Le Movie Watchlist du chapitre précédent, avec tous les éléments HTML remplacés par Naive UI.

#### `src/components/MovieCard.component.vue`

```vue
<template>
  <NCard :title="movie.title">
    <template #header-extra>
      <NTag :type="movie.seen ? 'success' : 'default'">
        {{ movie.seen ? '✓ Vu' : 'À voir' }}
      </NTag>
    </template>
    <p>{{ movie.genre }} — {{ movie.year }}</p>
    <template #footer>
      <NButton type="primary" @click="emit('toggle-seen', movie)">Basculer</NButton>
    </template>
  </NCard>
</template>

<script setup lang="ts">
import type { Movie } from '@/types'

interface MovieCardProps {
  movie: Movie
}

defineProps<MovieCardProps>()

const emit = defineEmits<{
  'toggle-seen': [movie: Movie]
}>()
</script>
```

#### `src/components/MovieList.component.vue`

```vue
<template>
  <NSpace vertical :size="16">
    <slot></slot>
    <p v-if="movies.length === 0">Aucun film pour l'instant.</p>
    <NGrid :cols="3" :x-gap="16" :y-gap="16">
      <NGi v-for="movie in movies" :key="movie.id">
        <MovieCard :movie="movie" @toggle-seen="emit('toggle-seen', $event)"/>
      </NGi>
    </NGrid>
  </NSpace>
</template>

<script setup lang="ts">
import type { Movie } from '@/types'
import MovieCard from './MovieCard.component.vue'

interface MovieListProps {
  movies: Movie[]
}

defineProps<MovieListProps>()

const emit = defineEmits<{
  'toggle-seen': [movie: Movie]
}>()
</script>
```

#### `src/pages/HomePage.vue`

```vue
<template>
  <div>
    <MovieList :movies="movies" @toggle-seen="onToggleSeen">
      <NSpace justify="space-between" align="center">
        <NInput v-model:value="search" placeholder="Rechercher un film..."/>
        <NTag type="success">{{ seenMovies.length }} vu(s) sur {{ movies.length }}</NTag>
      </NSpace>
    </MovieList>
  </div>
</template>

<script setup lang="ts">
import { ref, computed, watch, onMounted } from 'vue'
import type { Movie } from '@/types'
import MovieList from '../components/MovieList.component.vue'

const search = ref<string>('')

const movies = ref<Movie[]>([
  { id: 1, title: 'Inception', genre: 'Sci-Fi', year: 2010, seen: true },
  { id: 2, title: 'The Dark Knight', genre: 'Action', year: 2008, seen: false },
  { id: 3, title: 'Interstellar', genre: 'Sci-Fi', year: 2014, seen: false },
  { id: 4, title: 'Parasite', genre: 'Thriller', year: 2019, seen: true },
  { id: 5, title: 'Dune', genre: 'Sci-Fi', year: 2021, seen: false },
  { id: 6, title: 'Everything Everywhere All at Once', genre: 'Action', year: 2022, seen: true },
])

const seenMovies = computed(() =>
  movies.value.filter((m) => m.seen)
)

watch(search, (newVal) => {
  console.log('Recherche :', newVal)
})

onMounted(() => {
  console.log('Application prête')
})

const onToggleSeen = (movie: Movie) => {
  movie.seen = !movie.seen
}
</script>
```
