## Pourquoi utiliser une librairie UI ?

Sans librairie UI, chaque bouton, formulaire, modal ou grille doit être conçu et stylisé manuellement. Cela représente un effort considérable pour maintenir une cohérence visuelle dans l'ensemble de l'application.

Une librairie UI comme **Naive UI** offre :
- Des **composants préconçus** (boutons, formulaires, tableaux, modales, etc.)
- Un **design cohérent** appliqué uniformément
- Des composants **accessibles** et **testés**
- Un **gain de temps** pour se concentrer sur la logique métier

## Naive UI

**Naive UI** est une librairie de composants Vue 3, conçue pour TypeScript et compatible avec le mode sombre. Elle propose plusieurs centaines de composants documentés et personnalisables.

### Installation

```sh
npm install naive-ui
```

### Configuration globale

Il est recommandé d'enregistrer Naive UI **globalement** dans `main.ts`. Ainsi, tous les composants sont disponibles dans tout le projet sans avoir besoin de les importer un par un.

```ts
// main.ts
import naive from 'naive-ui'
import { createPinia } from 'pinia'
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'

const app = createApp(App)
app.use(createPinia())
app.use(router)
app.use(naive) // Enregistrement global de Naive UI
app.mount('#app')
```

## Composants essentiels

### NButton

```vue
<template>
  <NButton type="primary" @click="handleClick">Valider</NButton>
  <NButton type="error" :disabled="isLoading">Supprimer</NButton>
  <NButton quaternary @click="cancel">Annuler</NButton>
</template>
```

Types disponibles : `default`, `primary`, `info`, `success`, `warning`, `error`.

### NCard

```vue
<template>
  <NCard title="Mon titre" bordered>
    <p>Contenu de la carte</p>
    <template #footer>
      <NButton type="primary">Action</NButton>
    </template>
  </NCard>
</template>
```

### NInput et NForm

Pour les formulaires, Naive UI propose `NForm`, `NFormItem` et `NInput` avec validation intégrée.

```vue
<template>
  <NForm :model="form" :rules="rules" ref="formRef">
    <NFormItem label="Email" path="email">
      <NInput v-model:value="form.email" placeholder="votre@email.com" />
    </NFormItem>
    <NFormItem label="Mot de passe" path="password">
      <NInput
        v-model:value="form.password"
        type="password"
        show-password-on="click"
      />
    </NFormItem>
    <NButton type="primary" @click="handleSubmit">Se connecter</NButton>
  </NForm>
</template>

<script setup lang="ts">
import type { FormInst, FormRules } from 'naive-ui'
import { reactive, ref } from 'vue'

const formRef = ref<FormInst | null>(null)

const form = reactive({
  email: '',
  password: '',
})

const rules: FormRules = {
  email: [{ required: true, message: 'Email requis', trigger: 'blur' }],
  password: [{ required: true, message: 'Mot de passe requis', trigger: 'blur' }],
}

const handleSubmit = () => {
  formRef.value?.validate((errors) => {
    if (!errors) {
      console.log('Formulaire valide', form)
    }
  })
}
</script>
```

### NModal

```vue
<template>
  <NButton @click="showModal = true">Ouvrir</NButton>

  <NModal v-model:show="showModal" preset="card" title="Confirmation" style="width: 400px">
    <p>Êtes-vous sûr de vouloir supprimer cet élément ?</p>
    <template #footer>
      <NSpace justify="end">
        <NButton @click="showModal = false">Annuler</NButton>
        <NButton type="error" @click="confirmDelete">Supprimer</NButton>
      </NSpace>
    </template>
  </NModal>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const showModal = ref<boolean>(false)

const confirmDelete = () => {
  console.log('Supprimé')
  showModal.value = false
}
</script>
```

### NGrid et NGi

Pour la mise en page responsive en colonnes :

```vue
<template>
  <NGrid :cols="3" :x-gap="16" :y-gap="16">
    <NGi v-for="card in cards" :key="card.id">
      <NCard :title="card.name">
        <p>{{ card.description }}</p>
      </NCard>
    </NGi>
  </NGrid>
</template>
```

### NSpace

`NSpace` gère facilement l'espacement entre éléments :

```vue
<template>
  <NSpace vertical :size="16">
    <NCard title="Carte 1">Contenu</NCard>
    <NCard title="Carte 2">Contenu</NCard>
  </NSpace>

  <NSpace justify="space-between" align="center">
    <span>Titre</span>
    <NButton type="primary">Action</NButton>
  </NSpace>
</template>
```

### NTag

Pour afficher des étiquettes ou des badges :

```vue
<template>
  <NTag type="success">Actif</NTag>
  <NTag type="error" closable @close="removeTag">À supprimer</NTag>
</template>
```

### NSelect

Pour les listes déroulantes :

```vue
<template>
  <NSelect
    v-model:value="selectedDeck"
    :options="deckOptions"
    placeholder="Choisir un deck"
  />
</template>

<script setup lang="ts">
import { ref } from 'vue'

const selectedDeck = ref<number | null>(null)

const deckOptions = [
  { label: 'Deck Feu', value: 1 },
  { label: 'Deck Eau', value: 2 },
]
</script>
```

## Résumé des composants les plus utilisés

| Composant | Usage |
| --- | --- |
| `NButton` | Boutons d'action |
| `NCard` | Cartes de contenu |
| `NInput` | Champs de saisie |
| `NForm` / `NFormItem` | Formulaires avec validation |
| `NModal` | Boîtes de dialogue |
| `NGrid` / `NGi` | Mise en page en grille |
| `NSpace` | Espacement entre éléments |
| `NTag` | Étiquettes et badges |
| `NSelect` | Listes déroulantes |

> **Documentation complète :** [naiveui.com](https://www.naiveui.com/en-US/os-theme/components/button)
