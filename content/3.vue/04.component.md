Dans ce chapitre, on continue de construire notre Movie Watchlist en découpant le composant du chapitre précédent en composants réutilisables : `MovieCard` et `MovieList`.

## Le fichier de types

Avant de créer des composants, on centralise les interfaces TypeScript partagées dans un fichier dédié. Cela évite de redéfinir `Movie` dans chaque composant.

```ts
// src/types/index.ts

export interface Movie {
  id: number
  title: string
  genre: string
  year: number
  seen: boolean
}
```

Le type `Movie` est partagé entre tous les composants. Les types de props, eux, sont définis directement dans le fichier du composant concerné — ils lui sont propres et n'ont pas à être partagés.

```ts
import type { Movie } from '@/types'
```

## Création et utilisation d'un composant

Les **composants** sont des éléments réutilisables qui permettent de structurer une application Vue en morceaux indépendants. Chaque composant est un fichier `.vue` qui encapsule son template, sa logique et ses styles.

Reprenons l'exemple précédent et extrayons l'affichage d'un film dans un composant dédié.

```vue
<!-- src/components/MovieCard.component.vue -->
<template>
  <div>
    <p>{{ movie.title }} ({{ movie.year }}) — {{ movie.genre }}</p>
    <span v-if="movie.seen">✓ Vu</span>
    <span v-else>À voir</span>
    <button @click="emit('toggle-seen', movie)">Basculer</button>
  </div>
</template>

<script setup lang="ts">
import type { Movie } from '@/types'

interface MovieCardProps {
  movie: Movie
}

defineProps<MovieCardProps>()
const emit = defineEmits<{ 'toggle-seen': [movie: Movie] }>()
</script>
```

```vue
<!-- src/App.vue -->
<template>
  <div>
    <MovieCard :movie="movies[0]" @toggle-seen="onToggleSeen" />
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import type { Movie } from '@/types'
import MovieCard from './components/MovieCard.component.vue'

const movies = ref<Movie[]>([
  { id: 1, title: 'Inception', genre: 'Sci-Fi', year: 2010, seen: true },
])

const onToggleSeen = (movie: Movie) => {
  movie.seen = !movie.seen
}
</script>
```

> **Remarque :** Vue 3 avec `<script setup>` importe automatiquement les composants dans le template dès qu'ils sont importés dans le script. Pas besoin de les déclarer dans `components: {}`.

## Props : passer des données au composant enfant

Les **props** sont aux composants ce que les **paramètres sont aux fonctions** : elles permettent de passer des données depuis l'extérieur pour personnaliser le comportement.

Tout comme on ne peut pas modifier un paramètre de fonction depuis l'intérieur et s'attendre à ce que ça change la variable de l'appelant, **un composant enfant ne doit jamais modifier directement une prop** — c'est le parent qui en est propriétaire.

#### Composant enfant (`MovieCard.component.vue`)

```vue
<template>
  <div>
    <h3>{{ movie.title }}</h3>
    <p>{{ movie.genre }} — {{ movie.year }}</p>
    <span v-if="movie.seen">✓ Vu</span>
    <span v-else>À voir</span>
  </div>
</template>

<script setup lang="ts">
import type { Movie } from '@/types'

interface MovieCardProps {
  movie: Movie
}

defineProps<MovieCardProps>()
</script>
```

#### Composant parent (`HomePage.vue`)

```vue
<template>
  <div>
    <MovieCard
      v-for="movie in movies"
      :key="movie.id"
      :movie="movie"
    />
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import type { Movie } from '@/types'
import MovieCard from './components/MovieCard.component.vue'

const movies = ref<Movie[]>([
  { id: 1, title: 'Inception', genre: 'Sci-Fi', year: 2010, seen: true },
  { id: 2, title: 'The Dark Knight', genre: 'Action', year: 2008, seen: false },
  { id: 3, title: 'Interstellar', genre: 'Sci-Fi', year: 2014, seen: false },
])
</script>
```

> **TypeScript :** Définir les props avec `defineProps<MovieCardProps>()` permet à TypeScript de valider les types à la compilation. Si vous devez donner des valeurs par défaut, utilisez `withDefaults(defineProps<MovieCardProps>(), { ... })`.

## Émission d'événements : du composant enfant vers le parent

Lorsqu'un composant enfant doit communiquer avec son parent, on utilise `defineEmits<{}>()` pour déclarer les événements émis.

#### Composant enfant (`MovieCard.component.vue`)

```vue
<template>
  <div>
    <h3>{{ movie.title }}</h3>
    <p>{{ movie.genre }} — {{ movie.year }}</p>
    <span v-if="movie.seen">✓ Vu</span>
    <span v-else>À voir</span>
    <button @click="emit('toggle-seen', movie)">Basculer</button>
  </div>
</template>

<script setup lang="ts">
import type { Movie } from '@/types'

interface MovieCardProps {
  movie: Movie
}

defineProps<MovieCardProps>()

const emit = defineEmits<{
  'toggle-seen': [movie: Movie]
}>()
</script>
```

#### Composant parent (`HomePage.vue`)

```vue
<template>
  <div>
    <p v-if="lastToggled">Dernier film modifié : {{ lastToggled.title }}</p>
    <MovieCard
      v-for="movie in movies"
      :key="movie.id"
      :movie="movie"
      @toggle-seen="onToggleSeen"
    />
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import type { Movie } from '@/types'
import MovieCard from './components/MovieCard.component.vue'

const movies = ref<Movie[]>([
  { id: 1, title: 'Inception', genre: 'Sci-Fi', year: 2010, seen: true },
  { id: 2, title: 'The Dark Knight', genre: 'Action', year: 2008, seen: false },
])

const lastToggled = ref<Movie | null>(null)

const onToggleSeen = (movie: Movie) => {
  movie.seen = !movie.seen
  lastToggled.value = movie
}
</script>
```

> **Convention de nommage :** Les événements sont déclarés en `kebab-case` (`toggle-seen`) et écoutés en `kebab-case` dans le template parent (`@toggle-seen`).

## Slots : injecter du contenu dans un composant

Les **slots** permettent au composant parent d'injecter du contenu HTML dans un emplacement défini par l'enfant.

#### Composant enfant avec slot (`MovieList.component.vue`)

```vue
<template>
  <div>
    <slot></slot>
    <ul>
      <li
        v-for="movie in movies"
        :key="movie.id"
        :class="{ seen: movie.seen }"
        @click="emit('toggle-seen', movie)"
      >
        {{ movie.title }} — {{ movie.year }}
        <span v-if="movie.seen">✓</span>
      </li>
    </ul>
  </div>
</template>

<script setup lang="ts">
import type { Movie } from '@/types'

interface MovieListProps {
  movies: Movie[]
}

defineProps<MovieListProps>()

const emit = defineEmits<{
  'toggle-seen': [movie: Movie]
}>()
</script>
```

#### Composant parent utilisant le slot

```vue
<template>
  <div>
    <MovieList :movies="seenMovies" @toggle-seen="onToggleSeen">
      <h2>Films vus ({{ seenMovies.length }})</h2>
    </MovieList>
  </div>
</template>

<script setup lang="ts">
import { computed, ref } from 'vue'
import type { Movie } from '@/types'
import MovieList from './components/MovieList.component.vue'

const movies = ref<Movie[]>([
  { id: 1, title: 'Inception', genre: 'Sci-Fi', year: 2010, seen: true },
  { id: 2, title: 'The Dark Knight', genre: 'Action', year: 2008, seen: false },
  { id: 3, title: 'Interstellar', genre: 'Sci-Fi', year: 2014, seen: false },
])

const seenMovies = computed(() =>
  movies.value.filter((m) => m.seen)
)

const onToggleSeen = (movie: Movie) => {
  movie.seen = !movie.seen
}
</script>
```

## Exemple complet

Le même Movie Watchlist qu'au chapitre précédent, refactorisé en composants. Chaque fichier a une responsabilité claire.

#### `src/components/MovieCard.component.vue`

```vue
<template>
  <li :class="{ seen: movie.seen }">
    {{ movie.title }} ({{ movie.year }}) — {{ movie.genre }}
    <span v-if="movie.seen">✓ Vu</span>
    <span v-else>À voir</span>
    <button @click="emit('toggle-seen', movie)">Basculer</button>
  </li>
</template>

<script setup lang="ts">
import type { Movie } from '@/types'

interface MovieCardProps {
  movie: Movie
}

defineProps<MovieCardProps>()

const emit = defineEmits<{
  'toggle-seen': [movie: Movie]
}>()
</script>
```

#### `src/components/MovieList.component.vue`

```vue
<template>
  <div>
    <slot></slot>
    <p v-if="movies.length === 0">Aucun film vu pour l'instant.</p>
    <ul>
      <MovieCard
        v-for="movie in movies"
        :key="movie.id"
        :movie="movie"
        @toggle-seen="emit('toggle-seen', $event)"
      />
    </ul>
  </div>
</template>

<script setup lang="ts">
import type { Movie } from '@/types'
import MovieCard from './MovieCard.component.vue'

interface MovieListProps {
  movies: Movie[]
}

defineProps<MovieListProps>()

const emit = defineEmits<{
  'toggle-seen': [movie: Movie]
}>()
</script>
```

#### `src/pages/HomePage.vue`

```vue
<template>
  <div>
    <MovieList :movies="movies" @toggle-seen="onToggleSeen">
      <input v-model="search" placeholder="Rechercher un film..."/>
      <p>{{ seenMovies.length }} film(s) vu(s) sur {{ movies.length }}</p>
    </MovieList>
  </div>
</template>

<script setup lang="ts">
import { ref, computed, watch, onMounted } from 'vue'
import type { Movie } from '@/types'
import MovieList from '../components/MovieList.component.vue'

const search = ref<string>('')

const movies = ref<Movie[]>([
  { id: 1, title: 'Inception', genre: 'Sci-Fi', year: 2010, seen: true },
  { id: 2, title: 'The Dark Knight', genre: 'Action', year: 2008, seen: false },
  { id: 3, title: 'Interstellar', genre: 'Sci-Fi', year: 2014, seen: false },
  { id: 4, title: 'Parasite', genre: 'Thriller', year: 2019, seen: true },
  { id: 5, title: 'Dune', genre: 'Sci-Fi', year: 2021, seen: false },
  { id: 6, title: 'Everything Everywhere All at Once', genre: 'Action', year: 2022, seen: true },
])

const seenMovies = computed(() =>
  movies.value.filter((m) => m.seen)
)

watch(search, (newVal) => {
  console.log('Recherche :', newVal)
})

onMounted(() => {
  console.log('Application prête')
})

const onToggleSeen = (movie: Movie) => {
  movie.seen = !movie.seen
}
</script>
```

## Organisation des fichiers

```
src/
├── components/
│   ├── MovieCard.component.vue
│   └── MovieList.component.vue
├── pages/
│   └── HomePage.vue
├── types/
│   └── index.ts          ← Movie (modèles partagés)
├── App.vue
└── main.ts
```

> **Convention :** Les modèles de données partagés (comme `Movie`) vont dans `src/types/index.ts`. Les types de props (`MovieCardProps`, `MovieListProps`) se définissent directement dans le fichier du composant — ils lui appartiennent.
