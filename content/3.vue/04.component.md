Dans ce chapitre, on continue de construire notre Movie Watchlist en découpant le composant du chapitre précédent en composants réutilisables : `MovieCard`, `SearchBar` et `MovieList`.

## Création et utilisation d'un composant

Les **composants** sont des éléments réutilisables qui permettent de structurer une application Vue en morceaux indépendants. Chaque composant est un fichier `.vue` qui encapsule son template, sa logique et ses styles.

Reprenons l'exemple précédent et extrayons l'affichage d'un film dans un composant dédié.

```vue
<!-- src/components/MovieCard.component.vue -->
<template>
  <div>
    <p>{{ movie.title }} ({{ movie.year }}) — {{ movie.genre }}</p>
    <span v-if="movie.seen">✓ Vu</span>
    <span v-else>À voir</span>
    <button @click="emit('toggle-seen', movie)">Basculer</button>
  </div>
</template>

<script setup lang="ts">
import type { Movie } from '@/types'

defineProps<{ movie: Movie }>()
const emit = defineEmits<{ 'toggle-seen': [movie: Movie] }>()
</script>
```

```vue
<!-- src/App.vue -->
<template>
  <div>
    <MovieCard :movie="movies[0]" @toggle-seen="onToggleSeen" />
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import MovieCard from './components/MovieCard.component.vue'
import type { Movie } from '@/types'

const movies = ref<Movie[]>([
  { id: 1, title: 'Inception', genre: 'Sci-Fi', year: 2010, seen: true },
])

const onToggleSeen = (movie: Movie) => {
  movie.seen = !movie.seen
}
</script>
```

> **Remarque :** Vue 3 avec `<script setup>` importe automatiquement les composants dans le template dès qu'ils sont importés dans le script. Pas besoin de les déclarer dans `components: {}`.

## Props : passer des données au composant enfant

Les **props** permettent à un composant parent de transmettre des données à un composant enfant. En Vue 3, on les définit avec la macro `defineProps<{}>()` (pas d'import nécessaire).

#### Composant enfant (`MovieCard.component.vue`)

```vue
<template>
  <div>
    <h3>{{ movie.title }}</h3>
    <p>{{ movie.genre }} — {{ movie.year }}</p>
    <span v-if="movie.seen">✓ Vu</span>
    <span v-else>À voir</span>
  </div>
</template>

<script setup lang="ts">
interface Movie {
  id: number
  title: string
  genre: string
  year: number
  seen: boolean
}

const props = defineProps<{
  movie: Movie
}>()
</script>
```

#### Composant parent (`HomePage.vue`)

```vue
<template>
  <div>
    <MovieCard
      v-for="movie in movies"
      :key="movie.id"
      :movie="movie"
    />
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import MovieCard from './components/MovieCard.component.vue'

interface Movie {
  id: number
  title: string
  genre: string
  year: number
  seen: boolean
}

const movies = ref<Movie[]>([
  { id: 1, title: 'Inception', genre: 'Sci-Fi', year: 2010, seen: true },
  { id: 2, title: 'The Dark Knight', genre: 'Action', year: 2008, seen: false },
  { id: 3, title: 'Interstellar', genre: 'Sci-Fi', year: 2014, seen: false },
])
</script>
```

> **TypeScript :** Définir les props avec `defineProps<{}>()` permet à TypeScript de valider les types à la compilation. Si vous devez donner des valeurs par défaut, utilisez `withDefaults(defineProps<{}>(), { ... })`.

## Émission d'événements : du composant enfant vers le parent

Lorsqu'un composant enfant doit communiquer avec son parent, on utilise `defineEmits<{}>()` pour déclarer les événements émis.

Supposons que je veuille qu'un clic sur "Basculer" dans `MovieCard` notifie le parent pour qu'il mette à jour les données.

#### Composant enfant (`MovieCard.component.vue`)

```vue
<template>
  <div>
    <h3>{{ movie.title }}</h3>
    <p>{{ movie.genre }} — {{ movie.year }}</p>
    <span v-if="movie.seen">✓ Vu</span>
    <span v-else>À voir</span>
    <button @click="emit('toggle-seen', movie)">Basculer</button>
  </div>
</template>

<script setup lang="ts">
interface Movie {
  id: number
  title: string
  genre: string
  year: number
  seen: boolean
}

defineProps<{
  movie: Movie
}>()

const emit = defineEmits<{
  'toggle-seen': [movie: Movie]
}>()
</script>
```

#### Composant parent (`HomePage.vue`)

```vue
<template>
  <div>
    <p v-if="lastToggled">Dernier film modifié : {{ lastToggled.title }}</p>
    <MovieCard
      v-for="movie in movies"
      :key="movie.id"
      :movie="movie"
      @toggle-seen="onToggleSeen"
    />
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import MovieCard from './components/MovieCard.component.vue'

interface Movie {
  id: number
  title: string
  genre: string
  year: number
  seen: boolean
}

const movies = ref<Movie[]>([
  { id: 1, title: 'Inception', genre: 'Sci-Fi', year: 2010, seen: true },
  { id: 2, title: 'The Dark Knight', genre: 'Action', year: 2008, seen: false },
])

const lastToggled = ref<Movie | null>(null)

const onToggleSeen = (movie: Movie) => {
  movie.seen = !movie.seen
  lastToggled.value = movie
}
</script>
```

> **Convention de nommage :** Les événements sont déclarés en `camelCase` dans `defineEmits` (`toggleSeen`) ou en `kebab-case` (`toggle-seen`) et écoutés en `kebab-case` dans le template parent (`@toggle-seen`). Vue effectue la conversion automatiquement.

## Slots : injecter du contenu dans un composant

Les **slots** permettent au composant parent d'injecter du contenu HTML dans un emplacement défini par l'enfant. C'est le mécanisme d'extension et de composition des composants.

#### Composant enfant avec slot (`MovieList.component.vue`)

```vue
<template>
  <div>
    <!-- Emplacement pour le header (titre, barre de recherche...) -->
    <slot></slot>

    <ul>
      <li
        v-for="movie in movies"
        :key="movie.id"
        @click="emit('toggle-seen', movie)"
      >
        {{ movie.title }} — {{ movie.year }}
        <span v-if="movie.seen">✓</span>
      </li>
    </ul>
  </div>
</template>

<script setup lang="ts">
interface Movie {
  id: number
  title: string
  genre: string
  year: number
  seen: boolean
}

defineProps<{
  movies: Movie[]
}>()

const emit = defineEmits<{
  'toggle-seen': [movie: Movie]
}>()
</script>
```

#### Composant parent utilisant le slot

```vue
<template>
  <div>
    <MovieList :movies="filteredMovies" @toggle-seen="onToggleSeen">
      <!-- Ce contenu est injecté dans le <slot> de MovieList -->
      <div>
        <h2>Ma Watchlist</h2>
        <input v-model="search" placeholder="Rechercher un film..." />
      </div>
    </MovieList>
  </div>
</template>

<script setup lang="ts">
import { computed, ref } from 'vue'
import MovieList from './components/MovieList.component.vue'

interface Movie {
  id: number
  title: string
  genre: string
  year: number
  seen: boolean
}

const search = ref<string>('')
const movies = ref<Movie[]>([
  { id: 1, title: 'Inception', genre: 'Sci-Fi', year: 2010, seen: true },
  { id: 2, title: 'The Dark Knight', genre: 'Action', year: 2008, seen: false },
])

const filteredMovies = computed(() =>
  movies.value.filter((m) =>
    m.title.toLowerCase().includes(search.value.toLowerCase())
  )
)

const onToggleSeen = (movie: Movie) => {
  movie.seen = !movie.seen
}
</script>
```

## Organisation des fichiers

Une structure courante pour les composants Vue :

```
src/
├── components/           # Composants réutilisables
│   ├── MovieCard.component.vue
│   ├── MovieList.component.vue
│   └── SearchBar.component.vue
├── pages/                # Composants-pages (liés au router)
│   ├── HomePage.vue
│   └── WatchlistPage.vue
├── types/                # Interfaces TypeScript partagées
│   └── index.ts
├── App.vue
└── main.ts
```

> **Convention :** Nommer les composants réutilisables avec le suffixe `.component.vue` et les pages avec `.vue` (ou `.page.vue`). Les interfaces partagées entre plusieurs composants vont dans `src/types/`.
