Dans ce chapitre, on connecte le Movie Watchlist à une API REST : les films sont récupérés depuis le backend au lieu d'être déclarés en dur dans le composant.

## Pourquoi appeler une API ?

Jusqu'ici, les films étaient déclarés directement dans le composant. En réalité, les données viennent d'un **backend** via des appels HTTP : récupération de la liste, mise à jour du statut vu, etc.

Vue ne fournit pas de client HTTP intégré. Ce cours utilise **`fetch` natif**, disponible partout sans dépendance supplémentaire.

## Rappel : fetch natif

```ts
// GET
const response = await fetch('https://api.example.com/movies')
const movies = await response.json()

// PATCH
const response = await fetch('https://api.example.com/movies/1', {
  method: 'PATCH',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ seen: true }),
})
const updated = await response.json()
```

> `fetch` ne rejette pas la promesse en cas d'erreur HTTP (404, 500…). Il faut vérifier `response.ok` manuellement.

## Variables d'environnement

L'URL de base de l'API est configurée via une variable d'environnement Vite :

```sh
# .env
VITE_API_BASE_URL=http://localhost:3001/api
```

Accessible dans le code via `import.meta.env.VITE_API_BASE_URL`.

## Appels API dans un composant

`onMounted` est le hook idéal pour déclencher un appel API au chargement d'une page. On gère localement les états `isLoading` et `error`.

```vue
<!-- src/pages/HomePage.vue -->
<template>
  <div>
    <p v-if="isLoading">Chargement...</p>
    <p v-else-if="error">{{ error }}</p>
    <MovieList v-else :movies="movies" @toggle-seen="onToggleSeen">
      <NSpace justify="space-between" align="center">
        <NInput v-model:value="search" placeholder="Rechercher un film..."/>
        <NTag type="success">{{ seenMovies.length }} vu(s) sur {{ movies.length }}</NTag>
      </NSpace>
    </MovieList>
  </div>
</template>

<script setup lang="ts">
import { ref, computed, watch, onMounted } from 'vue'
import type { Movie } from '@/types'
import MovieList from '../components/MovieList.component.vue'

const BASE_URL = import.meta.env.VITE_API_BASE_URL

const search = ref<string>('')
const movies = ref<Movie[]>([])
const isLoading = ref<boolean>(false)
const error = ref<string | null>(null)

const seenMovies = computed(() =>
  movies.value.filter((m) => m.seen)
)

watch(search, (newVal) => {
  console.log('Recherche :', newVal)
})

onMounted(async () => {
  isLoading.value = true
  try {
    const res = await fetch(`${BASE_URL}/movies`)
    if (!res.ok) throw new Error(`Erreur ${res.status}`)
    movies.value = await res.json()
  }
  catch (e) {
    error.value = e instanceof Error ? e.message : 'Erreur inconnue'
  }
  finally {
    isLoading.value = false
  }
})

const onToggleSeen = async (movie: Movie) => {
  await fetch(`${BASE_URL}/movies/${movie.id}/toggle`, { method: 'PATCH' })
  movie.seen = !movie.seen
}
</script>
```
