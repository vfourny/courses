# Cours IUT — Valentin Fourny

Plateforme de cours en ligne pour les étudiants de l'IUT, couvrant Node.js, Vue.js, CI/CD et Git.

## Contenu des cours

| Cours | Thèmes abordés |
| --- | --- |
| **Node.js** | Bases, modules, TypeScript, API REST, Express, ORM, tests, Socket.io |
| **Vue.js** | Réactivité, composants, routing, Pinia, appels API, Socket.io |
| **CI/CD** | Linter, commits conventionnels, GitHub Actions, déploiement |
| **Git** | Bases, GitHub, workflows, merge/rebase |

## Développement

```bash
npm install
npm run dev
```

L'application est accessible sur `http://localhost:3000`.

## Autres commandes

```bash
npm run build      # build de production
npm run preview    # prévisualiser le build en local
npm run lint       # linter
npm run typecheck  # vérification des types
```
